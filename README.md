# Instituto Sophia

Site institucional desenvolvido para o Instituto Sophia, com o objetivo de apresentar a instituição, divulgar suas campanhas e mostrar formas de contribuir com seu trabalho.

## Sobre o projeto

O site reúne informações sobre a instituição, as pessoas atendidas, as campanhas realizadas e o bazar beneficente. Também possui uma seção dedicada às doações via Pix e links para as redes sociais.

O projeto busca apresentar essas informações de forma organizada e facilitar a navegação dos visitantes.

## Funcionalidades

* Apresentação da instituição;
* Seção sobre as pessoas atendidas;
* Vídeo institucional;
* Divulgação de campanhas;
* Informações sobre o bazar beneficente;
* Área para doações via Pix;
* Links para redes sociais;
* Layout adaptado para diferentes tamanhos de tela.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server para visualizar o site durante o desenvolvimento.

## Publicação

O projeto pode ser hospedado gratuitamente pelo GitHub Pages.
